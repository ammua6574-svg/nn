# Aviate™ Overseas Education — Study MBBS in Timor-Leste

Modern, high-performance web platform for **Aviate™ Overseas Education**, guiding Indian 12th PCB medical aspirants and parents to pursue an accredited MBBS degree at **Universidade Católica Timorense (UCT)** in Dili, Timor-Leste.

---

## 🌟 Key Features & Design System Highlights

- **Atmospheric Backgrounds per Section**:
  - 🏠 **Hero**: Deep Navy (`#071C42`) to Coastline Teal (`#0FA3A3`) diagonal mesh with Timor-Leste SVG topographic contour linework and soft glowing warm coral radial blobs.
  - 🌏 **Why Timor-Leste**: Full-bleed aerial coastline photo (Dili bay) with 65% navy-teal gradient overlay and signature dotted flight-path motif (India ✈ Timor-Leste).
  - 🎓 **MBBS Program**: Clinical pale teal wash (`#EAF7F6`) with subtle medical cross/DNA helix linework and floating credential cards.
  - 🏛️ **University (UCT)**: Navy-to-deep-teal architectural silhouette panel and soft sand (`#F6F1E7`) info-grid cards.
  - 💰 **Fees**: Off-white ledger grid background, solid coral-orange total tuition card, and interactive **USD ($) / INR (₹)** currency converter toggle.
  - ✅ **Eligibility**: Soft green wash (`#F1FAF5`), green left-accent checklist cards, and interactive **Instant Eligibility Checker** widget.
  - 🧭 **Process**: Warm sand background with connected 9-step curved flight route roadmap.
  - ❓ **FAQ**: Minimal off-white with watermark graphic, category filters, and smooth hover-shadow accordions.
  - 📩 **Contact & Free Counselling**: Deep navy gradient with topographic lines, frosted-glass contact cards, and responsive form validation.
  - 💬 **WhatsApp & Emergency Call**: Floating pulsating trigger with pre-filled consultation message.

- **Design System Tokens**:
  - **Primary Navy**: `#0B2E6B` → `#071C42`
  - **Accent Coral**: `#FF7A29` → `#FF904D`
  - **Coastline Teal**: `#0FA3A3` → `#EAF7F6`
  - **Warm Sand**: `#F6F1E7`
  - **Success Green**: `#1FAE6B`
  - **Typography**: Display headlines in `Outfit` / `Plus Jakarta Sans`, body in `Inter`.
  - **Contrast**: Full WCAG AA compliance across dark and light sections.

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/ammua6574-svg/nn.git
cd nn

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```
